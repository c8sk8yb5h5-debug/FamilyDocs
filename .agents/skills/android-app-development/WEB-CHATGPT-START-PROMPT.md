# ChatGPT 网页版 Android 开发启动指令

每次在 ChatGPT 网页版开始 Android App 开发时，复制下面这段话，并填写仓库地址和需求。

## 启动指令

请按目标 GitHub 仓库中的 `AGENTS.md` 和 `.agents/skills/android-app-development/SKILL.md` 执行开发。

仓库：`填写 GitHub 仓库地址`
需求：`填写本次开发目标`

先读取规范和项目现状，再搜索 GitHub 上可复用的成熟项目；简要汇报方案后再实施。完成后检查代码变更、运行可用的测试和构建，并核实交付物。只报告实际验证过的结果；无法访问文件或执行操作时，明确说明。使用中文，保持 UI 极简并加入有意义的交互动效，同时遵守目标项目自身的设计规范。

## 使用说明

- 将仓库地址和本次需求替换后，直接发送到 ChatGPT 网页聊天框。
- GitHub 插件需已连接，并且有权访问目标仓库。
- 这是一条手动启动指令，不会自动注册为 ChatGPT 原生 Skill。
